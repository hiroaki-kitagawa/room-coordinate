# room-coordinate

家具をドラッグ＆ドロップして、自分だけの部屋をつくる2Dルームコーディネートゲームです。

## 起動方法

`index.html` をブラウザで開いてください。ビルドやパッケージのインストールは不要です。

ローカルサーバーを使う場合は、プロジェクトのルートで次のように実行できます。

```powershell
python -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。

## 構成

- `index.html`：画面構造
- `styles.css`：レイアウトとビジュアル
- `app.js`：ドラッグ、配置判定、状態管理
- `docs/仕様書.md`：ゲーム仕様書

## 操作方法

- 家具一覧から部屋へドラッグして配置します。
- 配置済み家具をドラッグすると移動できます。
- 配置済み家具をクリックして選択し、「回転」ボタンを押すと90度ずつ回転します。
- キーボードでは家具にフォーカスして `R` キーでも回転できます。
- 選択後に「左右反転」ボタンを押すと向きを反転できます。キーボードでは `F` キーを使用します。
- ラグは床レイヤーに配置され、テーブルなどの家具を上に重ねられます。
